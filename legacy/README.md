# Legacy TypeScript Implementation

This directory contains the original TypeScript/Node.js implementation of the KOI sensor network.

## Key Differences from Current Python Implementation

- **Language**: TypeScript/Node.js vs Python
- **Sensors**: Includes discourse, github, gitlab, medium sensors not in current version
- **Architecture**: Different coordinator and framework approach

## Original Package Details

- Version: 1.0.0
- Main sensors: discourse, github, gitlab, medium, notion, podcast, twitter, web
- Built with TypeScript, using axios, commander, dotenv, node-cron, winston

## Migration Notes

This implementation was preserved when consolidating duplicate koi-sensors directories.
The current active implementation is in the parent directory using Python.
